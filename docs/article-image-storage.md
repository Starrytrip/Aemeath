# 文章图片的后端存储

文章正文与详情封面现在保存后端图片地址，例如：

```markdown
![示例图片](</api/v1/uploads/media-内容哈希.webp>)
```

文件保存在后端 `data/uploads`，素材信息保存在 `media_images`，文章通过 URL 引用素材。
前台直接加载后端返回的图片地址，不再请求前端构建资源映射。

现有本地文章的图片可先执行 `pnpm images:migrate` 预览，确认后加 `--apply`。
迁移读取后端当前正文，保留原图格式、透明度、正文文字、文章 ID、发布日期和发布状态；自动备份数据库，不删除前端原图。
源文件再次同步时，会先上传本地图片，再将正文和封面中的引用替换为后端地址。

日常在后台上传图片、粘贴图片或从图库选择图片即可；单个 Markdown 文件不包含旁边的图片目录。
数据库和 `data/uploads` 需要一起备份。具体参数、限制和恢复注意事项见 `backend/README.md` 的“文章原图迁移与存储”。
