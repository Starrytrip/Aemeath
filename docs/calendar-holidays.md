# 日历农历与节假日

侧栏日历在公历日期下显示农历；遇到节气、节日时优先显示名称，鼠标悬停或点击日期可查看完整农历、节日与调休信息。右上角「休」为已公布的假期，「班」为调休补班；圆点仍代表文章，当日文章筛选和年度热力图保留。

农历、传统节日和节气通过 `lunar-typescript` 在本地计算，避免依赖不同浏览器内置农历数据的差异。放假和补班使用 `src/config/calendarHolidays.ts` 中的中国大陆官方年度安排，每年附原文链接。目前已收录2026、2027年；后续官方公告发布后，补充对应年度并重新构建。未收录年份仍显示农历与节日，但不推测「休／班」，会注明调休安排暂未收录。普通周末不标成法定假期。

日历不依赖第三方日历接口；文章数据请求失败也不影响日期展示。

文章圆点、按日筛选和年度热力图直接读取后端 `/api/v1/articles` 的已发布文章，使用后端 `date` 字段，按本地日历日期处理，避免时区换算错位。点击文章进入 `/reader/?slug=...` 读取后端正文。页面切换或重新聚焦时重新请求，不保留旧静态元数据缓存；接口失败时显示提示并清空文章标记，农历与节假日继续显示。

本地文章同步直接读取源文件的 frontmatter，不依赖前端构建。缺失或无效发布日期会在同步前报错；后台已有的日期以后端为准，显式运行源文件同步时会按源文件中的发布日期更新。

验证：`pnpm exec tsx --test src/utils/calendar-day.test.ts`。
