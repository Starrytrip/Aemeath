# 导航文章搜索

聊天室、开往暂时从导航配置隐藏，页面和链接预设保留。搜索位于导航标签外的工具区，输入后显示最多6篇文章建议；标题匹配优先，再匹配摘要、分类、标签和正文。只展示文章，结果内容按纯文本渲染。

点击结果打开对应文章；点击搜索按钮或直接按回车进入带当前关键词的搜索页。方向键选择结果后，回车打开该文章；Escape、清空输入或点击外部关闭下拉。手机聚焦输入框时展开到导航栏宽度，下拉适配屏幕宽度。

导航下拉与搜索页的默认“文章搜索”统一调用 `GET /api/v1/search/articles?q=关键词&limit=20&offset=0`，直接查询后端文章记录，只返回已发布文章。匹配标题、摘要、分类、标签和正文，支持分页；结果跳转 `/reader/?slug=…`，由阅读页加载后端正文。普通文档、草稿、已下架和已删除文章不会混入文章搜索。

输入采用180ms防抖，取消旧请求并忽略过期响应。搜索响应不缓存，后台发布、编辑、下架或删除后，下次搜索即可反映更新，不需要重新构建静态索引。后端不可用时显示错误，不回退到静态文章或 Pagefind。搜索词在下拉标题、摘要和分类中继续高亮显示。

搜索页的“文档搜索”仍调用独立的通用文档搜索接口，供检索已收录文档与语义搜索使用。

旧同步脚本导入的 `astro-posts:` 记录也是文章，后台启动及保存同步记录时会自动补齐缺失的文章 Slug，避免因旧记录缺少元信息而漏搜；草稿、私有和已下架记录仍不公开。

部署本次修改时需同时更新前端和 Rust 后端，并重启后端服务；旧后端不包含新增的文章搜索接口。
